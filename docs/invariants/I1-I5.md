# Invariant Guarantees

## I1: At most one live booking per slot
**Guarantee:** Partial unique index `UNIQUE (slot_id) WHERE status <> 'cancelled'` + compare-and-set on `slots.status`
**How it works:** Two concurrent requests both reach `UPDATE slots SET status='booked' WHERE status='open'`; the second blocks on row lock, re-evaluates, matches zero rows, returns 409. The unique index is an independent last-line guard.
**Evidence:** `docs/evidence/concurrency-report.md`
**Verification query:** `SELECT slot_id, count(*) FROM bookings WHERE status <> 'cancelled' GROUP BY slot_id HAVING count(*) > 1;` — must return 0 rows.

## I2: No two slots of one provider overlap
**Guarantee:** `EXCLUDE USING gist (provider_id WITH =, tstzrange(slot_start_utc, slot_end_utc, '[)') WITH &&)`
**How it works:** Postgres exclusion constraint rejects overlapping ranges. Defense-in-depth with `UNIQUE (provider_id, slot_start_utc)`.
**Evidence:** `packages/db/src/constraint-tests.test.ts`, `docs/evidence/dst-matrix.md`
**Verification:** CI schema guard asserts constraints exist in `pg_constraint`.

## I3: Stored times are UTC instants; wall-clock math in one package
**Guarantee:** `@chronos/time` is the only module importing Temporal; ESLint bans `new Date(`, `Date.now()`, `moment`, `dayjs`, `date-fns-tz`, `node-cron`, `@nestjs/schedule` outside `clock.ts`.
**How it works:** All time arithmetic uses `subtractElapsed`, `isCancellable`, `reminderFireTimes`, `generateSlots`. Postgres stores `timestamptz`, never converts zones for business logic.
**Evidence:** `docs/evidence/dst-matrix.md` — suite runs under `TZ=UTC`, `TZ=Asia/Kolkata`, `TZ=America/Los_Angeles` with identical results.

## I4: Each (booking, reminder offset) yields at most one send effect
**Guarantee:** `UNIQUE(booking_id, offset_minutes)` + claim state machine + provider idempotency key
**How it works:** Worker claims DB first (`UPDATE SET status='sending'`), sends provider second, marks `sent` last. Provider idempotency key `reminder/{bookingId}/{offset}`. Redis is only the delivery timer (F5: Postgres is source of truth).
**Evidence:** `docs/evidence/reminder-report.md` — 0 duplicate reminders across N bookings × K retries.

## I5: Cancellation window evaluated in elapsed time on server clock
**Guarantee:** Pure function `isCancellable(now, slotStart, windowHours)` + injected `Clock`.
**How it works:** `deadline = slot_start_utc − window_hours` using elapsed time (not clock-time arithmetic). Boundary tests verify exact edge allowed, 1ms after denied, 24h window spanning DST still 24 real hours.
**Evidence:** `docs/evidence/lifecycle-report.md`, `apps/api/src/bookings/lifecycle.test.ts`
